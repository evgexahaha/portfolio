# Exodus Light — Портфолио Full-Stack Разработчика

Современный лендинг-портфолио с анимациями, тёмной/светлой темой и адаптивным дизайном.

![Preview](https://img.shields.io/badge/Status-Completed-success)
![License](https://img.shields.io/badge/License-MIT-blue)

---

## 🚀 Особенности

- **Анимации**: Печатающийся текст, плавное появление элементов, параллакс-эффекты
- **Темы**: Переключение между тёмной и светлой темой с сохранением в localStorage
- **Адаптивность**: Полная поддержка мобильных устройств (до 480px)
- **Счётчики**: Анимированные счётчики статистики при скролле
- **Навигация**: Плавная прокрутка к секциям, мобильное меню

## 🚀 Запуск

### Локально
Просто откройте `index.html` в браузере:
```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

### Через локальный сервер
```bash
# Используя Python
python -m http.server 8000

# Используя Node.js (требуется http-server)
npx http-server -p 8000
```

Затем откройте `http://localhost:8000`

## 🎯 Ключевые функции

### Печатающийся текст
```javascript
const phrases = [
    'Full-Stack разработчик',
    'UI/UX Дизайнер',
    'Воплощаю идеи в коде',
    'Технологический энтузиаст',
];
```

### Переключение темы
- Сохранение выбора в localStorage
- Плавная анимация иконки
- CSS-переменные для быстрой смены цветов

### Анимация при скролле
- Intersection Observer для отслеживания видимости
- Анимированные счётчики статистики
- Появление карточек и текста
