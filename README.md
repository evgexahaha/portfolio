# Exodus Light – Портфолио Full-Stack Разработчика

Современный лендинг-портфолио с анимациями, тёмной/светлой темой и адаптивным дизайном.

![Preview](https://img.shields.io/badge/Status-Completed-success)
![License](https://img.shields.io/badge/License-MIT-blue)

---

## Особенности

- **Анимации**: Печатающийся текст, плавное появление элементов, параллакс-эффекты
- **Темы**: Переключение между тёмной и светлой темой с сохранением в localStorage
- **Адаптивность**: Полная поддержка мобильных устройств (до 480px)
- **Счётчики**: Анимированные счётчики статистики при скролле
- **Навигация**: Плавная прокрутка к секциям, мобильное меню

## Секции сайта

1. **Главная** – Приветствие, печатающийся текст, кнопки призыва к действию
2. **Обо мне** – Информация о разработчике, статистика проектов
3. **Навыки** – Карточки с технологиями (Frontend, Backend, Инструменты, Дизайн)
4. **Контакты** – Email и ссылка на GitHub

## Цветовая палитра

### Тёмная тема (по умолчанию)
```css
--bg-primary: #0f0f23;
--bg-secondary: #1a1a2e;
--primary-color: #6366f1;
--secondary-color: #8b5cf6;
--accent-color: #06b6d4;
```

### Светлая тема
```css
--bg-primary: #f8fafc;
--bg-secondary: #ffffff;
--text-primary: #1e293b;
```
